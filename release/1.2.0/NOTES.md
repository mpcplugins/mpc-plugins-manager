- **Gen1 owners see more plugins in the main list.** A plugin tested on Gen2 that comes as one download for every MPC
  (made with the MPC Plugin SDK) is now shown with the tested plugins on a Gen1 too, marked "Tested on Gen2, built for
  Gen1", instead of on the red Untested tab. The same the other way round. Installing it still asks for a second tap.

**Install:** download `MPC-Plugins-Manager-1.2.0-mpc-sdk.zip`, unzip it, copy the folder `The Disk King - VST - MPC Plugins Manager` into `VST2 Plugins` on your MPC, restart, add a Plugin track and pick External Plugins > The Disk King > MPC Plugins Manager, then tap the arrow next to its name. Needs MPC OS 3.10.1 with Enable Enhancements and External Plugin Support on. Full guide: https://thediskking.com/plugins/install/
